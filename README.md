# RWS — Minecraft 1.16.5 Fabric Mod

Приватный клиентский мод автоматизации для Minecraft 1.16.5 (Fabric).

## Возможности

- Последовательный проход по списку аккаунтов (каждый со своим прокси SOCKS5 / HTTP)
- Смена ника клиента на лету (cracked-сессии)
- Подключение к серверу (по умолчанию `ru.reallyworld.me`) с индивидуальным прокси
- Автоматический сценарий: `/login` → компас → печка → 3-я голова → команда → `/sellfish` → кликер по пороху до триггера «Работы » Достигнут лимит» → `/balance` → `/pay <получатель> <баланс>`
- Бинд **Старт / Пауза / Продолжить** (одна клавиша) — через стандартное меню «Настройки → Управление → RWS»
- Бинд **Открыть настройки**
- Красивый GUI конфигурации (cloth-config + Mod Menu) с разделами **Общие / Аккаунты / Статус**
- В разделе «Статус» — текущее состояние, текущий аккаунт, текущий шаг и журнал из последних 50 записей

## Сборка

```bash
./gradlew build
```

Готовый `.jar` появится в `build/libs/rws-<version>.jar`.

## Зависимости рантайма

- Fabric Loader ≥ 0.14.0
- Fabric API
- Cloth Config (`cloth-config2`)
- Mod Menu (опционально — для быстрого доступа к настройкам)

## Конфиг

Файл `config/rws.json` создаётся автоматически при первом запуске. Редактировать можно и вручную, и через внутриигровой GUI (клавиша настраивается в «Управлении»).

Формат строки аккаунта в GUI (через `|`):
```
nickname|password|SOCKS5|proxyHost|proxyPort|proxyUser|proxyPass|proxyEnabled
```
Пример:
```
Player1|mypass|SOCKS5|127.0.0.1|1080|user|pass|true
Player2|mypass2|HTTP|127.0.0.1|8080|||false
```

## Назначение клавиш

По умолчанию бинды **не назначены**. Назначь их в `Настройки → Управление → RWS`:
- `Старт / Пауза автоматизации`
- `Открыть настройки RWS`
